# Product Context

## Problem Statement

Agentic systems lack the ability to generate trustworthy code in production systems repeatable and dependably.

## Proposed Approach

Provenance-aware agentic knowledge graphs: agents will retrive information and write updates to a knowledge graph layer of data from Ebay development teams.

## Key Differentiators

The provenance-aware agentic knowledge graphs is our differentiator. Also the practical application of this infrastructure in real-world development settings.

## Target Audience

Software developers, managers, and researchers at eBay
